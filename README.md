# 질문수업 진행판

교과서를 펴고 [제목]과 [이름] 두 칸만 채우면, 오늘 칠판에 쓸 판서와 40분 진행 순서가 바로 나오는 교사용 패드 웹앱입니다. 초등 6학년 교실에서 '질문이 있는 교실' 수업 틀로 쓰려고 만들었어요.

- **교과서 중심 아날로그 수업:** 아이들은 칠판, 교과서, 종이 배움노트로 공부해요. 패드는 선생님만 들어요.
- **쉽게 시작해서 조금씩 깊게:** 1단계 '교과서 함께 읽기'에서 시작해요. 수업을 마칠 때마다 칸이 차고, 6·8·10·12번을 채우면 다음 단계(질문판 → 근거로 말하기 → 루틴 바꿔 끼우기 → 아이들이 이끄는 질문)를 열 수 있어요. 아이들이 벅찼던 날은 칸을 세지 않아요.
- **사고가시화 루틴:** 하버드 Project Zero의 루틴(보고·생각하고·궁금해하기, 무엇을 보고 그렇게 말해?, 헤드라인, 주장·근거·질문, 줄다리기 등)을 단계에 맞춰 넣었어요.
- **교탁에서 교실 TV 조종:** 교실 컴퓨터를 'TV 화면'으로 두면 핵심질문, 지금 단계, 남은 시간이 따라가요. 패드에서 보낸 유튜브 링크는 TV에서 바로 재생돼요.

## 바로 써 보기

로그인 없이도 쓸 수 있어요. 이때 진행 기록은 그 기기에만 저장되고, TV 연결은 꺼져 있어요.

## 내 것으로 만들기 (약 15분)

### 1. 저장소 복사

이 저장소 오른쪽 위 **Fork**를 눌러 내 깃허브로 복사해요.

### 2. 파이어베이스 프로젝트 만들기

[파이어베이스 콘솔](https://console.firebase.google.com)에서:

1. **프로젝트 추가** → 이름(예: `question-board`) → 구글 애널리틱스는 꺼도 돼요.
2. **빌드 → Authentication → 시작하기 → Google** 사용 설정 → 지원 이메일 고르기 → 저장.
3. **Authentication → 설정 → 승인된 도메인 → 도메인 추가** → `내아이디.github.io`.
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드로 시작.
   **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여 넣고 **게시**.
5. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`)** → 앱 이름 입력 → 등록 → 화면에 나온 `firebaseConfig` 값을 복사해요.

무료 플랜(Spark)으로 충분해요. 이 앱은 파일 저장소(Storage)를 쓰지 않아서 결제 계정이 필요 없어요.

### 3. 설정값 넣기

`config.js`를 열어 5번에서 복사한 값을 붙여 넣고 저장(커밋)해요. 이 값은 웹 페이지에 공개돼도 괜찮은 값이고, 데이터는 `firestore.rules`가 지켜 줘요.

### 4. 웹 주소 만들기

저장소 **Settings → Pages → Branch: main / (root) → Save**. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 열려요.

## 교실에서 쓰는 법

1. **선생님 패드:** 주소를 열고 구글로 로그인해요. 홈 화면에 추가해 두면 앱처럼 열려요.
2. **교실 컴퓨터(TV에 연결된 컴퓨터):** 같은 주소 뒤에 `#tv`를 붙여 열거나 '이 기기를 TV 화면으로'를 눌러요. 같은 구글 계정으로 로그인하고, 아침에 **전체 화면**을 한 번 눌러 두세요. 그래야 영상이 소리와 함께 바로 재생돼요.
3. **수업 중:** 패드에서 단계를 넘기면 TV가 따라와요. 'TV 화면 끄기'로 아이들 눈을 칠판으로 돌릴 수 있어요.
4. **영상:** 유튜브 링크는 TV에서 바로 재생돼요. 퍼가기를 막아 둔 영상이나 다른 사이트 링크는 TV에 노란 '열기' 버튼으로 떠요. TV 도우미 학생이 한 번 눌러 주면 돼요.

## 저장되는 것

- 선생님 계정 아래(`users/{uid}`)에 단계, 마친 수업 수, 최근 수업 60개(날짜·교과·소단원 제목·반응), 학생 수만 저장해요.
- 학생 이름이나 번호는 저장하지 않아요. 노트 당번은 날짜로 계산해서 번호만 보여 줘요.
- 다른 선생님은 내 기록을 볼 수 없어요.

## 파일

| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 (칠판, 패드, TV 화면) |
| `app.js` | 질문 만들기, 40분 단계, 단계 올리기, 파이어베이스 연결, TV |

| `firestore.rules` | 보안 규칙 (콘솔에 붙여 넣어요) |
